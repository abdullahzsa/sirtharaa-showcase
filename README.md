# Resume Document Preview & Export Engine

A lightweight, standalone React showcase demonstrating:
- In-browser PDF rasterization and live A4 document canvas rendering.
- Multiple ATS-friendly typographic templates (Classic, Compact, Executive).
- Client-side export fidelity with zero server dependencies.
- Bilingual layout considerations (English & Arabic).

### Tech Stack
- React 19 + TypeScript
- pdf-lib & pdfjs-dist for client-side document rendering
- docx for Word exports
